# Decision Rules

> Status: Review · Owner: Dev Patel · Version: 1 · Last updated: 2026-09-28
> Source: Wolf v3 framework, `08_DECISIONS/DECISION-RULES.md` (imported unchanged apart from this header and "Applied in this repo")

Use:
WHY → EVIDENCE → OPTIONS → TRADE-OFFS → COST → RISK → DECISION → APPROVAL → CONSEQUENCES → REVISIT CONDITION.

Prefer the lowest-cost option satisfying required security, reliability, performance, compliance and user-value requirements.

## Applied in this repo

This is the same shape the "Engineering decision framework" in `05_ENGINEERING/ENGINEERING.md` and every entry under `08_DECISIONS/ENGINEERING/` and `08_DECISIONS/PRODUCT/` already uses (why / impact / how / cost / cost-justification / consequences / revisit condition), just named slightly differently. No entry needs reformatting to comply — the two phrasings are the same rule.
