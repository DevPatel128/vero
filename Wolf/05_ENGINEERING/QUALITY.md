# Quality

Testing layers:
unit, integration, API, authorization, RLS, end-to-end, accessibility, security, performance, failure/recovery, migration and AI evaluation.

For every high-risk path test:
- allowed behavior
- denied behavior
- malformed input
- adversarial input
- dependency failure
- rollback/recovery.

Quality gate: no known critical security issue, required tests pass, material risks documented, production approval satisfied.
