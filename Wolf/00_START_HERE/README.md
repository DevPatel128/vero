# AI-Native Product & Company Operating Framework

## Purpose
A reusable operating system for taking an idea from founder intent to researched product, design, software, launch, business, investment materials, operations, continuous improvement, and accountable AI-assisted execution.

## Core lifecycle
IDEA → INTERVIEW → RESEARCH → VIABILITY → THESIS → PRODUCT → EXPERIENCE → DESIGN → ARCHITECTURE → ENGINEERING → SECURITY → TEST → PREVIEW → APPROVAL → DEPLOY → OBSERVE → LEARN → UPDATE

## Non-negotiable operating principles
1. Research before consequential claims or recommendations.
2. Interview when founder intent is materially ambiguous.
3. Evidence before confidence.
4. One canonical source for every concept.
5. Every meaningful change explains WHY, IMPACT/RESULTS, HOW, COST, JUSTIFICATION.
6. AI assists; humans retain final authority over consequential product, legal, financial, safety, privacy, security-exception and production decisions.
7. Audit consequential AI actions end-to-end.
8. Security is enforced outside the model wherever possible.
9. Least privilege applies to humans, agents, tools, data and services.
10. Prefer the smallest architecture and minimum necessary code that still preserves correctness, security, readability, testability, reliability and maintainability.
11. Optimize measured bottlenecks; never sacrifice correctness or security for theoretical optimization.
12. Never fabricate facts, metrics, evidence, customers, sources, quotes, capabilities or outcomes.
13. Archive important history rather than silently deleting reasoning.
