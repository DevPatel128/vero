# External Framework Research

## Sources reviewed
- NIST AI Risk Management Framework: https://www.nist.gov/itl/ai-risk-management-framework
- NIST AI RMF Playbook: https://www.nist.gov/itl/ai-risk-management-framework/nist-ai-rmf-playbook
- OWASP AI Agent Security Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html
- OWASP Agent Control Standard: https://genai.owasp.org/resource/agent-control-standard-acs/
- OWASP Top 10 for Agentic Applications: https://genai.owasp.org/
- OWASP Prompt Injection guidance: https://genai.owasp.org/llmrisk/llm01-2025-prompt-injection/

## Incorporated ideas
- Govern/map/measure/manage AI risk across the lifecycle.
- Explicit human oversight.
- Least-privilege agent/tool access.
- External policy enforcement rather than trusting prompts as security controls.
- Action previews and approval binding for high-impact actions.
- Audit trails for agent decisions/tool calls/outcomes.
- Agent identity and controlled inter-agent communication.
- Prompt-injection and indirect-injection defense.
- Runtime monitoring and anomaly detection.
- AI-specific evaluation and adversarial testing.
- Data-access authorization at request time.
- Cost/token/resource budgets.
- Rollback and interruption for high-impact actions.
