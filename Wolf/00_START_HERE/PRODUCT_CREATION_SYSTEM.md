# Product Creation System

IDEA → INTERVIEW → RESEARCH → VIABILITY → THESIS → PRODUCT → EXPERIENCE → DESIGN → ARCHITECTURE → ENGINEERING → TEST → PREVIEW → APPROVAL → PRODUCTION → OBSERVE → IMPROVE

## Core rule
AI investigates, prepares, implements within authority, validates, documents and reviews. Humans retain final authority over consequential decisions.

## Universal change framework
Every meaningful change answers:
1. Why should we make it?
2. What impact/results should it create?
3. How will we implement it?
4. How much will it cost?
5. Is the cost justified?
6. What alternatives were considered?
7. What evidence supports it?
8. What could falsify the decision?
9. Who must approve it?
10. What must be logged and documented?

## Evidence hierarchy
Primary/official → authoritative secondary → credible independent → community evidence → model inference.
Never present model inference as external evidence.

## Lifecycle gates
- Discovery gate
- Research/viability gate
- Product gate
- Trust/security gate
- Design/accessibility gate
- Engineering quality gate
- Preview gate
- Production approval gate
- Post-launch observation gate

## Source of truth
PRINCIPLES = durable rules
PRODUCT = what
THESIS = why
RESEARCH = evidence
EXPERIENCE = user behavior
ENGINEERING = how
SECURITY = protection
DECISIONS = accepted/rejected reasoning
AUDIT = execution history
INVESTOR = investment narrative
