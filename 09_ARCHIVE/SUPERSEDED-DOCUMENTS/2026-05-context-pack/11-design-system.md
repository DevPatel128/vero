# Design System

## Objective
Define the visual language of VERO so the product feels premium, coherent, and maintainable across the website and application.

## Visual goals
The design should feel:
- calm
- intelligent
- premium
- modern
- minimal
- app-like
- trustworthy

## Color philosophy
Use a restrained palette. Colors should support clarity and trust, not overwhelm the user. The palette should work in light and dark modes if both are used.

Recommended approach:
- neutral base surfaces
- one or two strong brand accents
- subtle state colors for success, warning, and error
- minimal decorative color usage

## Typography
Typography should be clean, readable, and modern. The hierarchy should be obvious:
- large confident headlines
- clear section titles
- readable body text
- subtle captions and labels

Avoid overly stylized fonts that hurt clarity.

## Spacing system
Use a consistent spacing scale. The system should create rhythm across pages and components. Generous whitespace is part of the brand because it signals calm and premium quality.

## Radius and elevation
Use consistent border radius, subtle shadows, and restrained depth. The goal is soft polish, not heavy glass or exaggerated shadow noise.

## Cards
Cards are the core visual building block. They should:
- be easy to scan
- feel tactile
- support icons, stats, steps, and highlights
- adapt well to mobile
- have clear hierarchy

## Buttons
Buttons should be visually distinct and consistent:
- primary CTA
- secondary CTA
- subtle tertiary actions
- disabled and loading states
- accessible focus states

## Badges and chips
Badges should be used for:
- trust levels
- verification types
- career paths
- unlock status
- reputation labels

They should remain concise and meaningful.

## Motion style
Motion should be understated. Use gentle fade, slide, scale, and reveal patterns. Motion should support comprehension and brand quality, not become a distraction.

## Illustration and imagery style
If imagery is used, it should look credible and relevant. Prefer:
- mockups
- app previews
- clean icons
- editorial visuals
- lifestyle images that support the product story

Avoid generic stock clutter.

## Component consistency
Every component should follow the same design language:
- same spacing logic
- same typography scale
- same border behavior
- same hover quality
- same loading treatment

## Accessibility within design
Design must support contrast, readability, keyboard interaction, and screen-reader clarity. Beautiful design without accessibility is incomplete.

## Design system outcome
A user should be able to move across pages and feel that the same thoughtful system is guiding them. Nothing should feel pasted together.
