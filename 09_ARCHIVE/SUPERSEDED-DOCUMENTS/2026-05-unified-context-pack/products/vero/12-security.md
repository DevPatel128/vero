# 12 — Security

## Goal
Define the security and privacy posture for Vero.

## Must cover
- Authentication
- Password and key policy
- Session security
- Data protection
- Threat model
- Auditability
- Region-aware compliance constraints

## Security posture
Security should support trust by default and never feel bolted on.

## Anti-patterns
- DIY crypto
- Hidden data handling rules
- Security language that the product cannot back up
