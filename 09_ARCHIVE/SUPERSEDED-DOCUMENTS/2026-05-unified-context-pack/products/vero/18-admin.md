# 18 — Admin

## Goal
Define the back-office systems needed to run Vero safely.

## Must cover
- Moderation
- Verification review
- Dispute handling
- User and business support
- Audit views
- Operational controls

## Admin rule
Admin capability should exist to reduce risk and handle edge cases without undermining the product trust model.

## Anti-patterns
- Admin tools that can silently rewrite trust
- Support flows without audit trails
- Overpowered internal shortcuts
