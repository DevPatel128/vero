# 20 — AI Agent Rules

## Contract
Any AI agent editing Trove must load the relevant product context first.

## Rules
- Prefer existing structure
- Keep edits output-oriented
- Log every AI-driven change
- Update the pack when product truth changes
- Do not invent unsupported security or pricing claims

## Refuse to
- Drift from the context pack
- Guess at compliance or privacy details
- Change the theme without documentation
