# 07 — Trust

## Goal
Make discipline proof credible and difficult to fake.

## Trust model
- Sessions, outputs, and streaks should be verifiable
- Data sources should be explicit where possible
- Bad behavior should be detectable and reversible
- Reputation should follow honest participation

## Must cover
- Trust signals
- Validation logic
- Streak integrity
- Category-specific abuse prevention
- Cross-product trust portability

## Anti-patterns
- Fake streak mechanics
- Hidden validation rules
- Trust language that users cannot explain back
