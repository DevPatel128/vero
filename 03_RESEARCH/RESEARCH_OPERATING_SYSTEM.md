# Research Operating System

> Status: Review · Owner: Dev Patel · Version: 1 · Last updated: 2026-09-28
> Source: Wolf v3 framework, `03_RESEARCH/RESEARCH_OPERATING_SYSTEM.md` (imported unchanged apart from this header and "Applied in this repo")

Question → hypothesis → method → evidence → triangulation → synthesis → confidence → implication → decision → outcome → research debt.

Modes:
generative, evaluative, quantitative, qualitative, market, competitive, technical, security, legal/compliance and AI evaluation.

AI may monitor approved sources for changed assumptions, competitors, technology, regulation, customer behavior and security risk. Monitoring is permissioned and auditable.

## Applied in this repo

`03_RESEARCH/RESEARCH.md`'s 14-row evidence ledger is this system's output so far, all from source-document synthesis (no live source monitoring is running). Every row is labelled by evidence class (`FACT/EVIDENCE/INFERENCE/ASSUMPTION/PROJECTION/UNVERIFIED`); "research debt" — the questions this repo cannot yet answer — is the `UNVERIFIED`-labelled rows plus `DISCOVERY.md`'s "who was talked to" gap.
