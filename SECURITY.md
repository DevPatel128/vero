# Security policy

## Supported versions

Only the current `main` branch (the deployed website in `website/site/`) is supported. Vero is pre-launch.

## Reporting a vulnerability

Please report privately and do not open a public issue.

- Use GitHub's **Report a vulnerability** button on the Security tab of this repository, or
- email **security@vero.work**.

Include the affected URL or file, steps to reproduce, the impact you observed, and any suggested fix. Do not include real personal data, and do not test against other people's data.

We aim to acknowledge reports within two business days and to fix or mitigate confirmed issues within thirty days. There is no bug bounty at this time.

## Ground rules

- Give us reasonable time to fix an issue before disclosing it.
- Do not run denial-of-service, spam or social-engineering tests, and do not access data that is not yours.
- Never commit secrets. If you find a credential in this repository or its history, report it privately so it can be rotated.

The full public policy is at `/legal/responsible-disclosure` on the website.
