# 07 — Trust

## Goal
Make trust visible, understandable, and hard to fake.

## Trust model
- Completed work becomes signed proof
- Clients and workers both participate in the record
- Repeated good behavior should improve standing
- Bad behavior should reduce access

## What this file must cover
- Trust signals
- Verification logic
- Dispute handling
- Record visibility
- Repeat-offender handling
- Cross-product trust portability

## Anti-patterns
- Hidden trust scores
- Overly abstract credibility language
- Trust systems that users cannot explain back
