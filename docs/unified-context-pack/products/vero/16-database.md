# 16 — Database

## Goal
Define the main data structures and how they relate.

## Must cover
- Users
- Businesses
- Work records
- Verification records
- Trust signals
- Pricing and billing references
- Audit log references

## Database rules
- Store only what the product needs
- Preserve traceability
- Make record ownership explicit
- Support exportability and auditability

## Anti-patterns
- Silent schema sprawl
- Storing data without an owner
- Tables that do not map to product behavior
