# 20 — AI Agent Rules

## Contract
Any AI agent touching Vero files must load the relevant product context before editing.

## Rules
- Prefer existing structure
- Keep edits output-oriented
- Log the change if the AI touched files
- Update the context pack when product truth changes
- Do not invent unsupported pricing, compliance, or launch claims

## Refuse to
- Drift from the pack
- Guess at legal or pricing details
- Change the theme without documentation
- Hide source-of-truth mismatches
