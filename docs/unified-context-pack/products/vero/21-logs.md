# 21 — Logs

## Goal
Record Vero-specific edit history and product changes.

## What belongs here
- AI-driven changes
- Human edits that alter product truth
- Pricing changes
- Theme changes
- Compliance-sensitive updates

## Log fields
- Agent
- Timestamp
- Files changed
- Summary
- Reason
- Context-pack section
- Verification status

## Rule
If the pack changes, the log should reflect it. If the log changes, the reason should be clear.
