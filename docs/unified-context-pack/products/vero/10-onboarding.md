# 10 — Onboarding

## Goal
Make first use obvious and low-friction for workers and businesses.

## Onboarding paths
- Worker onboarding
- Business onboarding
- Verification flow
- First job / first hire flow
- Return-user recovery flow

## What this file must answer
- What is the first action?
- What does the user need to trust the system?
- Where can onboarding fail?
- How does the product recover from failure?

## Anti-patterns
- A long abstract setup process
- Forcing unnecessary steps before value appears
- Onboarding that feels different by device without reason
