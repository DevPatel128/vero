# 13 — Performance

## Goal
Keep the product fast, stable, and dependable.

## Must cover
- Rendering targets
- Latency expectations
- Bundle discipline
- Asset size discipline
- Caching strategy
- Monitoring and alerting

## Performance rule
Fast enough to feel trustworthy is part of the product, not an optimization afterthought.

## Anti-patterns
- Large unreviewed bundles
- Slow public pages
- Performance budgets without owners
