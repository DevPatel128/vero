# 11 — Design System

## Goal
Define the reusable visual system behind Vero.

## Must include
- Typography scale
- Color tokens
- Spacing rules
- Surface rules
- Button and form states
- Empty states
- Error states
- Loading states
- Accessibility rules

## System rule
The design system should make every product screen feel like it belongs to the same company.

## Anti-patterns
- Unnamed visual decisions
- One-off components that break consistency
- Accessibility treated as a late-stage fix
