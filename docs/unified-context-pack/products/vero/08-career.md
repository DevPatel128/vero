# 08 — Career

## Goal
Describe how a user grows through Vero over time.

## Progression
- Start with small work
- Build verified records
- Earn repeat trust
- Move into better jobs and stronger standing
- Carry the proof forward

## What this file should answer
- What does growth look like?
- How do users move from beginner to trusted worker?
- What milestones matter?
- How does Vero help people level up without inflating claims?

## Anti-patterns
- Career progress as vanity badges only
- Growth that is not connected to real work
- A progression system that feels like a game instead of a tool
