# 03 — Theme

## Theme goal
Keep Vero visually consistent across product, marketing, and exported HTML so the user feels one coherent system.

## Immutable system traits
- Calm tone
- Premium spacing
- Strong hierarchy
- Accessible contrast
- Minimal decorative clutter
- Consistent motion timing

## Allowed variation
- Small accent shifts for emphasis
- Product-specific examples
- Region-specific page content
- Page-level layout emphasis where needed

## Theme lock rules
- Shared tokens must not drift without documentation.
- HTML exports must reflect the same visual system as the Markdown source.
- New page styles must be justified against the existing family feel.

## Anti-patterns
- Different pages feeling like different companies
- Changing too many visual variables at once
- Letting investor-facing pages and product pages look unrelated
