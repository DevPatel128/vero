# 18 — Admin

## Goal
Define the operational tools needed to keep RIE reliable.

## Must cover
- Moderation
- Validation review
- Support tooling
- Fraud handling
- Audit views
- Operational controls

## Admin rule
Admin should help protect authenticity without making the product feel opaque.

## Anti-patterns
- Undocumented admin powers
- Hidden proof edits
- No audit trail for sensitive actions
