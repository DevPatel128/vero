# 16 — Database

## Goal
Define the main data structures and relationships.

## Must cover
- Users
- Discipline categories
- Sessions or proof events
- Streaks
- Validation references
- Trust markers
- Pricing references
- Audit logs

## Database rules
- Preserve provenance
- Keep validation explicit
- Support exports and summaries
- Map data to product behavior

## Anti-patterns
- Schema drift without a product reason
- Unowned records
- Tables that do not support verification
