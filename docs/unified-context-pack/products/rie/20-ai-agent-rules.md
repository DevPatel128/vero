# 20 — AI Agent Rules

## Contract
AI agents editing RIE must load the relevant RIE context before changing files.

## Rules
- Prefer existing structure
- Keep edits output-oriented
- Log every AI-driven change
- Update the pack when product truth changes
- Do not invent unsupported pricing or validation claims

## Refuse to
- Drift from the context pack
- Guess at policy or compliance
- Change the theme without documenting it
