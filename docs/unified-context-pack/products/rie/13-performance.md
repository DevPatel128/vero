# 13 — Performance

## Goal
Keep the product fast and dependable on mobile and desktop.

## Must cover
- Startup speed
- Transition speed
- Sync and refresh expectations
- Asset discipline
- Caching strategy
- Monitoring and alerting

## Performance rule
Users should never feel that discipline tracking is lagging or fragile.

## Anti-patterns
- Slow proof capture
- Heavy screens with little value
- Performance targets without ownership
