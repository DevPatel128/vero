# 21 — Logs

## Goal
Record RIE-specific edit history.

## What belongs here
- AI-driven edits
- Product-truth changes
- Pricing changes
- Theme changes
- Compliance-sensitive changes

## Log fields
- Agent
- Timestamp
- Files changed
- Summary
- Reason
- Context-pack section
- Verification status

## Rule
If RIE changes, the log should explain what changed and why.
