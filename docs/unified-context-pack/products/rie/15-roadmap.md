# 15 — Roadmap

## Goal
Describe the staged evolution of RIE.

## Roadmap phases
- Core proof capture
- Category launch
- Trust and streak maturity
- Better analytics and exports
- Cross-device expansion
- Ecosystem growth

## Rule
Each phase should deepen proof without weakening discipline authenticity.

## Anti-patterns
- Expanding before validation
- Roadmap items that depend on unsupported trust models
- Feature sprawl that outruns the core
