# 23 — Operations

## Goal
Document the operational work needed to keep RIE trustworthy.

## Must cover
- Support
- Validation review
- Moderation
- Monitoring
- Escalation paths
- Internal ownership

## Operations rule
If proof can be disputed, the operating model must explain the response path.

## Anti-patterns
- No owner for edge cases
- Support that cannot explain validation failures
- Invisible operations
