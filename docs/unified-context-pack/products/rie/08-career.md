# 08 — Career

## Goal
Describe progression through discipline, not hierarchy.

## Progression
- Start tracking a discipline
- Build repeatability
- Earn verified proof
- Improve output quality or consistency
- Carry that proof across contexts

## What this file should answer
- How does a user improve over time?
- What milestones matter?
- How do discipline signals become portable proof?

## Anti-patterns
- Career ladders that do not map to real effort
- Progress systems without verification
- Gamified language that overwhelms the product
