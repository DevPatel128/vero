# 22 — Launch

## Goal
Describe the launch posture for RIE.

## Launch content
- First categories
- First proof sources
- Early user positioning
- Invite or waitlist posture
- Launch communication rules

## Launch rule
RIE should feel precise and disciplined at launch, not broad or noisy.

## Anti-patterns
- Announcing more categories than the product can support
- Overpromising proof sources
- Launch copy that sounds generic
