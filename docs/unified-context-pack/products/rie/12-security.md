# 12 — Security

## Goal
Define the security and privacy posture for RIE.

## Must cover
- Authentication
- Data protection
- Device or source trust
- Threat model
- Auditability
- Region-aware privacy constraints

## Security posture
Security should support trustworthy proof without turning the product into a surveillance tool.

## Anti-patterns
- Hidden data collection
- Weak validation for proof inputs
- Security language that the product cannot support
