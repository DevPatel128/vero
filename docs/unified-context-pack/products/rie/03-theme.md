# 03 — Theme

## Theme goal
Keep RIE visually aligned with the shared family system while preserving a disciplined, high-signal feel.

## Immutable system traits
- Quiet confidence
- Clear hierarchy
- Accessible contrast
- Consistent spacing
- Calm motion
- Trusted system surfaces

## Allowed variation
- Small accent differences for discipline categories
- Product-specific imagery and examples
- Layout emphasis for athletes, creators, and gamers

## Theme lock rules
- Shared tokens must stay aligned with the umbrella pack.
- HTML output should match the Markdown source visually.
- Changes in motion or color require explicit documentation.

## Anti-patterns
- Loud fitness clichés
- Disconnected page styling
- A theme that looks like a different product family
