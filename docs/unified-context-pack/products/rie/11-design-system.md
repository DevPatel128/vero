# 11 — Design System

## Goal
Define the reusable visual system behind RIE.

## Must cover
- Typography scale
- Color tokens
- Spacing rules
- Surface rules
- Button and form states
- Loading and empty states
- Accessibility rules

## System rule
The visual system should make the product feel disciplined and legible.

## Anti-patterns
- One-off visuals that break consistency
- Fitness styling without restraint
- Accessibility pushed to the end
