# 10 — Onboarding

## Goal
Make first use calm, secure, and understandable.

## Onboarding paths
- Create an account
- Set up trust or security basics
- Add the first record
- Understand visibility and ownership
- Recover if setup is interrupted

## What this file must answer
- What is the first valuable action?
- What is required for trust?
- What happens when onboarding fails?

## Anti-patterns
- Overly complex first-run setup
- Too many steps before value
- Confusing privacy defaults
