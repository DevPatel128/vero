# 16 — Database

## Goal
Define the main data structures and relationships.

## Must cover
- Users
- Records
- Ownership and visibility
- Trust metadata
- Pricing references
- Audit logs
- Export references

## Database rules
- Preserve ownership
- Minimize unnecessary exposure
- Support exportability
- Keep provenance explicit

## Anti-patterns
- Data without a trust reason
- Unclear ownership boundaries
- Tables that encourage overexposure
