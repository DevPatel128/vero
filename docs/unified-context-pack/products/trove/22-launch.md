# 22 — Launch

## Goal
Describe the launch posture for Trove.

## Launch content
- First use cases
- First trust story
- Early user positioning
- Waitlist or invite posture
- Launch communication rules

## Launch rule
Trove should feel calm, useful, and trustworthy at launch.

## Anti-patterns
- Broad vague launch promises
- Privacy language that overreaches
- Launch copy that sounds like generic storage
