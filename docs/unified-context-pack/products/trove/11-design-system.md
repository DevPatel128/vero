# 11 — Design System

## Goal
Define the reusable visual system behind Trove.

## Must cover
- Typography scale
- Color tokens
- Spacing rules
- Surfaces and containers
- Form and button states
- Empty and error states
- Accessibility rules

## System rule
The visual system should make the product feel secure and legible.

## Anti-patterns
- Decorative clutter
- Inconsistent component behavior
- Accessibility as an afterthought
