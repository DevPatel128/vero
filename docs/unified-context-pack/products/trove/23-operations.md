# 23 — Operations

## Goal
Document the operational work needed to keep Trove safe.

## Must cover
- Support
- Moderation
- Monitoring
- Sensitive record handling
- Escalation paths
- Internal ownership

## Operations rule
If a user loses trust in the product, the operating model must explain how the issue is handled.

## Anti-patterns
- No owner for sensitive cases
- Support that cannot resolve privacy issues
- Invisible operations
