# 07 — Trust

## Goal
Make provenance, ownership, and record integrity visible and reliable.

## Trust model
- Durable records should have clear ownership
- Sensitive information should stay protected
- Provenance should be verifiable when needed
- Exportability should not weaken integrity

## Must cover
- Trust signals
- Ownership rules
- Record verification
- Privacy-preserving display
- Cross-product trust portability where applicable

## Anti-patterns
- Exposing private records by default
- Hidden ownership rules
- Trust language that is too abstract for users
