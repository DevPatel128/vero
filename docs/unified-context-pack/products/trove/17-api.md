# 17 — API

## Goal
Document the surfaces that create, retrieve, and export records.

## Must cover
- Public routes
- Authenticated routes
- Export endpoints
- Webhooks or integrations
- Idempotency rules
- Error handling
- Versioning

## API rule
APIs should make record handling predictable and auditable.

## Anti-patterns
- Unclear export behavior
- Hidden state changes
- Breaking updates without versioning
