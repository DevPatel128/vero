# 08 — Career

## Goal
For Trove, this file maps household or record-life progression rather than a traditional career path.

## Progression
- Start with a few important records
- Build a trusted record set
- Organize and export reliably
- Add more sensitive or valuable records over time
- Use provenance to reduce uncertainty

## What this file should answer
- How does a user deepen use over time?
- What does maturity look like?
- How does the product grow without becoming intrusive?

## Anti-patterns
- Pretending every product needs a career ladder
- Making growth feel like gamification
- Expanding storage without increasing trust
