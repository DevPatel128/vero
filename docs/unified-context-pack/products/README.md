# Products

This folder groups the product-specific context packs under the umbrella system.

## Product folders
- `vero/` — Vero product pack
- `rie/` — RIE product pack
- `trove/` — Trove product pack

## Rule
Each product folder should stay independently readable, but all three must still obey the umbrella rules for pricing, theme lock, logging, AI edits, and governance.
