# 08 — AI Agent Rules

## Contract
Any agent editing the repo must follow the context pack, the root project instructions, and the product-specific docs.

## Behavior rules
- Load the relevant context first.
- Prefer existing structures over inventing new ones.
- Keep edits output-oriented and minimal.
- Log changes as required.
- Do not introduce inconsistencies in theme, pricing, or governance.
- Consult the future-scopes file before proposing roadmap expansion or research-budget changes.

## Refuse to
- Guess at pricing or regulation
- Invent product behavior not supported by the pack
- Drift away from current product reality
- Skip logs when an AI made the change
