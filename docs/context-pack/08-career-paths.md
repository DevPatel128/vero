# Career Paths

## Objective
Define the first set of VERO career categories in a way that is practical, trust-based, and expandable. These should be the starting point of the apprenticeship and gig ecosystem, not the final list.

## Career philosophy
Each career path should satisfy three conditions:
1. repeat demand
2. proof-of-work visibility
3. trust-based growth

If a field does not support these well, it should not be a launch category yet.

## Positioning guidance
The site and product should present these fields as:
- real-world opportunity
- apprenticeship pathways
- credibility builders
- skill progression tracks
- respectable work

## Trust requirements by category
Different fields require different trust signals.
- Elderly assistance: strong background checks and emergency support
- Pet care: repeat-client trust and reliability
- Beauty and wellness: portfolio proof and client ratings
- Hospitality: punctuality and professionalism
- Fitness: safety and verification
- Event logistics: reliability and coordination

## Field expansion rule
Do not add too many categories at once. Add categories that can be executed well, verified well, and trusted locally. The product should deepen category quality before broadening category count.

## User flow
A career path should:
- explain the job type
- explain required skills
- show progression
- show proof examples
- show how trust grows
- show entry-level opportunities
- show future unlocks

## Why this matters
Career categories are not just filters. They define the user’s identity path. The categories should help users see themselves growing from beginner to trusted contributor.

## Expandable architecture
The career path system should support future additions. New categories should fit the same pattern:
- introduction
- skill map
- proof examples
- trust rules
- apprenticeship levels
- portfolio ideas
- category-specific safety rules

## Product outcome
The user should feel that VERO contains practical, respected, and expandable ways to grow through real work.
