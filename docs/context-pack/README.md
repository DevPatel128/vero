# VERO Context Pack

This folder contains the core markdown context files for the VERO project. The files are designed to reduce ambiguity for AI models and human builders by splitting the product into clear, single-purpose system documents.

## Usage
Load only the files relevant to the task first, then the supporting files. For example:
- website copy task: 00, 01, 02, 14, 10
- frontend task: 00, 03, 04, 11, 13
- trust task: 00, 01, 06, 12
- blockchain task: 00, 01, 07, 12
- backend task: 00, 04, 05, 16, 17, 18
- roadmap task: 00, 01, 15

The documents are written to work together as a stable context system for Claude Code, Gemini, Cursor, Paperclip, Antigravity, and similar AI agents.
