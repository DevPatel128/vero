# Copywriting Tone

## Objective
Define the language style so the website, onboarding, notifications, and future product copy all feel coherent.

## Tone summary
- clear
- calm
- premium
- intelligent
- confident
- human
- trust-first
- never hypey

## Voice rules
The voice should speak like a serious product company with a strong mission. It should avoid exaggerated claims and generic startup slogans.

## What the copy should do
- explain the product quickly
- reduce confusion
- establish trust
- motivate action
- make the user feel capable
- reinforce proof-of-work identity

## Language style
Use short, strong sentences where possible. Use plain English. If a concept is complex, explain it simply rather than sounding clever.

## Good themes
- build through action
- trust through proof
- progress through consistency
- credibility through work
- growth through real contribution

## CTA tone
Calls to action should be direct and useful:
- Join early access
- Explore career paths
- See how it works
- Build your profile
- Become a verified contributor

Avoid vague CTAs like:
- Learn more
- Submit
- Continue
- Let’s go

## Emotional copy
The copy should validate beginners without patronizing them. It should also reassure clients without sounding defensive.

## Forbidden language
Avoid:
- disruption without substance
- next-gen everything
- revolution in every sentence
- hustle-overload language
- fake urgency
- over-promising
- crypto slang

## Page-by-page style
- Home: bold, concise, reassuring
- What is VERO: explanatory and confident
- Trust & Verification: precise and safe
- Career Paths: practical and aspirational
- Manifesto: deep, calm, memorable
- FAQ: direct and helpful

## Social proof language
Testimonials or achievements should sound authentic, not overproduced. Trust grows when copy feels real.

## Copy logic
Before publishing any line, ask:
- Is it clear?
- Is it useful?
- Is it credible?
- Does it fit the brand?
- Does it help the user act?

If not, revise it.

## Copy outcome
The user should read the site and feel that the company knows exactly what it is building and why.
