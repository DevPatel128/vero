# Principles

This is the product constitution.

1. **User value first.** Every feature must solve a meaningful user problem.
2. **Complexity belongs in the system, not the user's head.**
3. **Simplicity is a product requirement.**
4. **User control.** Recommendations do not become decisions without user authority.
5. **Trust before growth.**
6. **Never fabricate.** Unknown is a valid answer.
7. **Evidence before confidence.**
8. **One source of truth.**
9. **Progressive disclosure.** Reveal capability when it becomes useful.
10. **No dark patterns.**
11. **Notifications must earn attention.**
12. **Privacy by design.**
13. **Research before consequential recommendations.**
14. **Distinguish facts from estimates and assumptions.**
15. **Do not manufacture urgency or problems.**
16. **Accessibility is part of quality.**
17. **Build the smallest honest version first.**
18. **Measure outcomes, not vanity.**
19. **If a feature adds complexity without proportional value, remove it.**
20. **Sincerity over sophistication.**
21. **Lowest justified cost.** Prefer the lowest-cost solution that satisfies required security, reliability, performance, compliance and user-value requirements.
22. **Secure by default.** Do not depend on users or developers remembering optional security steps.
23. **Public-safe by design.** Source code must remain safe to publish; secrets and sensitive data never belong in the repository.

### Final test

Does this make the user's life clearer, safer, easier, or more capable?

If not, reconsider it.
