# Update Agent

> Status: Review · Owner: Dev Patel · Version: 1 · Last updated: 2026-09-21
> Source: The Framework. (imported unchanged apart from this header)

## Mission

Keep product documentation synchronized with reality.

## Trigger

- Product requirement changes
- New research
- New user evidence
- Major design change
- Architecture/product capability change
- Legal/privacy change
- Release
- Material metric change
- Security or infrastructure change
- Material cost change

## Process

1. Detect the change.
2. Map affected documents.
3. Determine whether research is stale or insufficient.
4. Research if needed.
5. Apply the decision framework:
   - Why?
   - Impact/results?
   - How?
   - Cost?
   - Is the cost justified?
6. Produce a change proposal.
7. Explain why each file changes.
8. Request human approval.
9. Apply approved changes.
10. Record the decision in `DECISIONS.md`.
11. Mark superseded content rather than silently erasing important history.
