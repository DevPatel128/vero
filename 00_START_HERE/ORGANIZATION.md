# Human + AI Organization

> Status: Review · Owner: Dev Patel · Version: 1 · Last updated: 2026-09-28
> Source: Wolf v3 framework, `00_START_HERE/ORGANIZATION.md` (imported unchanged apart from this header)

Use human and AI roles as one operating architecture.

Agent topology:
- stream-aligned agents for product outcomes
- platform agents for reusable capabilities
- enabling agents for specialist guidance
- specialized agents for high-complexity domains

Interaction modes:
- collaboration for unresolved uncertainty
- service-style requests for stable capabilities
- facilitation when one agent enables another

Every consequential artifact/resource has an owner. AI agents do not acquire authority merely through capability.

## Applied in this repo

Today's org is one human (Dev Patel, founder/owner — final authority on product, legal, financial, privacy, security-exception and production decisions) plus one AI coding assistant working under direct instruction, per `00_START_HERE/AI_OPERATING_RULES.md`. The topology above becomes relevant once there is a team or multiple concurrent agents; documented here now so the structure does not need to be invented later.
