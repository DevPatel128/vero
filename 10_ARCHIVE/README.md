# 09_ARCHIVE

Status: Draft. Owner: Dev Patel. Version: 1. Last updated: 2026-09-21.

**Purpose:** keep historical reasoning without competing with current documents.

**Belongs here:** rejected ideas, superseded documents, old research, old decisions.
**Does not belong here:** anything current, anything an agent should follow.

**Rule:** never treat an archived or superseded document as current truth. Archive; do not delete.

| Folder | Holds |
|---|---|
| `REJECTED-IDEAS/` | Ideas considered and rejected, with the reason |
| `SUPERSEDED-DOCUMENTS/` | Documents replaced by a newer canonical one (see its README) |
| `OLD-RESEARCH/` | Research replaced by newer evidence |
| `OLD-DECISIONS/` | Decisions that were superseded (record, do not erase) |
