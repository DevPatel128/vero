# 06 — Revenue

## Revenue model
RIE uses a freemium model with paid pro features.

## Revenue paths
- Subscription tiers for power users
- Premium analytics and reporting
- API or integration access
- Future creator or team plans where justified

## Revenue questions
- Which users become paying users?
- What advanced behavior creates value worth paying for?
- Which features should stay free to protect adoption?

## Anti-patterns
- Charging before trust is built
- Weak feature gating
- Adding monetization that damages the discipline narrative
