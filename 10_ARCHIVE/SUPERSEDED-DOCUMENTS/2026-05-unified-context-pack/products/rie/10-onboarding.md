# 10 — Onboarding

## Goal
Make first use fast and understandable for athletes, creators, and gamers.

## Onboarding paths
- Choose a discipline category
- Connect or define a proof source
- Start the first tracked session
- Recover if a user skips a day or misses setup

## What this file must answer
- What is the first valuable action?
- What validation is required?
- What happens when onboarding fails?

## Anti-patterns
- Long setup without value
- Over-asking before proof appears
- Device pairing that feels opaque
