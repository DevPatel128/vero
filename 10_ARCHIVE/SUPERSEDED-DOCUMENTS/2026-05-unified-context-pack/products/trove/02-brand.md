# 02 — Brand

## Brand direction
Trove should feel careful, calm, private, and trustworthy. It should read like an infrastructure product, not a consumer toy.

## Voice
- Grown-up
- Clear
- Respectful
- Quiet
- Precise

## Messaging order
1. What Trove is
2. What it protects
3. Why provenance matters
4. How trust is preserved
5. How to join

## Visual feeling
- Restraint
- Strong structure
- Quiet confidence
- Minimal clutter

## Anti-patterns
- Flashy consumer storage language
- Overpromising security
- Visual noise that undermines trust
