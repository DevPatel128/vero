# 03 — Theme

## Theme goal
Keep Trove visually aligned with the shared system while making the privacy and provenance story feel calm and durable.

## Immutable system traits
- Quiet tone
- Clear spacing
- Strong readability
- High trust surfaces
- Accessible contrast
- Subtle motion

## Allowed variation
- More restrained accent usage
- Product-specific examples around records and value
- Small layout shifts for privacy-sensitive flows

## Theme lock rules
- Shared tokens should stay consistent with the umbrella pack.
- HTML output must mirror the source docs.
- Visual changes should be justified by user trust, not novelty.

## Anti-patterns
- Making the product feel decorative
- Using visual language that hides what the product does
- Diverging from the family system without reason
