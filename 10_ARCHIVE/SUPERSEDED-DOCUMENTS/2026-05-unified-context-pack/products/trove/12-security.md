# 12 — Security

## Goal
Define the privacy and security posture for Trove.

## Must cover
- Authentication
- Encryption expectations
- Data protection
- Threat model
- Auditability
- Region-aware compliance constraints

## Security posture
Security should be the product, not just a feature.

## Anti-patterns
- Weak handling of private records
- Generic security claims without controls
- Hidden access patterns
