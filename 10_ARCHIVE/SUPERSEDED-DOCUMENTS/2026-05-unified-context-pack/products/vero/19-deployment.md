# 19 — Deployment

## Goal
Define how Vero is deployed, monitored, and rolled back safely.

## Must cover
- Hosting model
- Environments
- CI/CD
- Release process
- Rollback behavior
- Disaster recovery
- Operational ownership

## Deployment rule
The deployment system should be boring, observable, and reversible.

## Anti-patterns
- Manual release mystery
- No rollback path
- Environment drift
