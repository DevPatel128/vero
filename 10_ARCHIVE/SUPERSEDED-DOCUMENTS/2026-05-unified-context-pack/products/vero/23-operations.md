# 23 — Operations

## Goal
Document the operating machinery needed to keep Vero healthy.

## Must cover
- Support
- Disputes
- Verification operations
- Moderation
- Monitoring
- Internal ownership
- Escalation paths

## Operations rule
If the product can fail in the real world, the operating model must describe what happens next.

## Anti-patterns
- No owner for edge cases
- A support path that cannot resolve disputes
- Operations treated as invisible
