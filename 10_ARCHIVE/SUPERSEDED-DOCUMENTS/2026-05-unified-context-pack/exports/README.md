# HTML Exports

This folder defines the reading/export layer for the unified context pack.

## Purpose
Make the pack easier to browse for investors, non-technical readers, and any stakeholder who prefers rendered pages over raw Markdown.
The primary preview is interactive: it includes audience toggles, animated reveal states, and charted sections.
It includes one self-contained HTML file that covers home, investor, user, company, tech, privacy, NDA, and future-scope views.

## Primary preview
- `index.html` — standalone local preview for the unified context pack

## Rule
- Markdown remains the source of truth.
- HTML is the reading/export layer.
- The export layer should stay consolidated into one HTML file unless a new requirement explicitly reintroduces split pages.
