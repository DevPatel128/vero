# 02 — Enterprise Fit

## Standard
This pack is enterprise-grade and future-proof, but it must stay anchored to Vero, RIE, Trove, and the website.

## Fit rules
- Every major section must map to at least one current product.
- If a section is broader than the current products, it must say so explicitly.
- If a section does not help the current products, it should not be elevated into the core pack.
- When the pack and the product disagree, the product reality wins and the mismatch is documented.

## What to check
- Product-market fit
- Pricing fit
- Theme consistency fit
- Localization fit
- Compliance fit
- Operational fit
- AI-edit workflow fit

## Anti-patterns
- Abstract enterprise language that no product actually uses
- Overengineering for hypothetical future products
- Pretending all products need the same feature set
