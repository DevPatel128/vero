# VERO Context File

## Product Identity
VERO is an AI-powered verified professional identity and proof-of-work infrastructure platform.

VERO is not:
- a job board
- a LinkedIn clone
- a gig marketplace

VERO is:
- professional trust infrastructure
- proof-of-work identity system
- employability intelligence layer
- behavioral reputation network
