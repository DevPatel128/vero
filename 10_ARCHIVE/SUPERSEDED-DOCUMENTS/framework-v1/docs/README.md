# Docs

Top-level documentation for the VROE Labs monorepo. Per-product depth lives in each app's `docs/context-pack/`.

| File                  | Scope                                                                |
| --------------------- | -------------------------------------------------------------------- |
| `ARCHITECTURE.md`     | Repo + system architecture, ALVED, deployment topology               |
| `DEPLOY.md`           | Vercel + DNS + env wiring per app                                    |
| `SECURITY.md`         | Crypto + auth + compliance posture (umbrella)                        |
| `NATIVE-ROADMAP.md`   | Expo / iOS / Android / watchOS / wearOS plan                         |
| `COMPLIANCE.md`       | Country-by-country compliance matrix (DPDP / GDPR / CCPA / LGPD / PIPL / POPIA) |

For per-product depth, see:

- [`/apps/vero/docs/context-pack/`](../apps/vero/docs/context-pack/README.md)
- [`/apps/rie/docs/context-pack/`](../apps/rie/docs/context-pack/README.md)
- [`/apps/trove/docs/context-pack/`](../apps/trove/docs/context-pack/README.md)

For the framework that produced these docs (reusable for any new product), see [`/framework/`](../framework/).
